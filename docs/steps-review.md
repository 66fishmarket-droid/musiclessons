# Per-step review

What each step shows besides its text. "More about this" is on every step.

## Fixed blocks

- **warmup**: 1. text only · 2. scale board + metronome · 3. scale board + metronome
- **apply**: 1. card + metronome · 2. card + chords + metronome · 3. card + chords + metronome
- **record**: 1. recorder · 2. recorder · 3. recorder
- **review / reset**: whole block (unchanged)

## Create tasks

### melody_135

1. A four-bar tune is a short melody that lasts four bars: one bar per chord, four beats per bar. → **text only**
2. Find it first: pick the notes {degrees:1,3,5} one at a time on the top strings until you like the order. The fretboard shows them as 1, 3 and 5. → **scale board**
3. Now play {chords} with the day's rhythm and sing (or hum) the tune over it, one bar per chord. → **chords**
4. Record it with the app's recorder and listen back once. → **chords + recorder**

### question_answer

1. Play {chords}, one bar per chord. → **chords**
2. Over the first two bars, sing a short phrase that ends on the note {degrees:5}. It sounds unfinished, like a question. → **chords + scale board**
3. Over the last two bars, sing a phrase that ends on the note {degrees:1}. It sounds like home, the answer. → **chords + scale board**
4. Record it with the app's recorder and listen back once. → **chords + recorder**

### rhyming_couplet

1. Look around and pick one object. Write two short lines about it that rhyme. → **text only**
2. Play {chords}, one bar per chord, and speak the lines in time with the strum: line one over the first two bars, line two over the last two. → **chords**
3. Now sing them, each line on one held pitch: line one on the note {degrees:1} over the first two bars, line two on the note {degrees:5} over the last two. Keep the pitch steady and let the chords move under you. → **chords + scale board**
4. Record it with the app's recorder and listen back once. → **chords + recorder**

### new_feel

1. Play {chords} with the rhythm from the Apply block, one bar per chord. → **chords**
2. Change exactly one thing: move the bass note to a different beat, or leave one strum out. → **chords**
3. Hum or sing any line over the new feel and notice what changed in the mood. → **chords**
4. Record it with the app's recorder and listen back once. → **chords + recorder**

### one_note_verse

1. Play {chords}, one bar per chord. → **chords**
2. Sing or speak any line of words, keeping every syllable on the note {degrees:1}. → **chords + scale board**
3. Listen to how the same note feels different over each chord. → **chords**
4. Record it with the app's recorder and listen back once. → **chords + recorder**

## fretboard

### Notes on strings 6 and 5 (card: note_caller)

1. Strings 6 and 5 are E and A when played open. The dots on the neck at frets 3, 5, 7, 9 and 12 are your landmarks: on string 6 they are G, A, B, C# and E; on string 5 they are C, D, E, F# and A. → **text only**
2. Between two letter names there is one fret for the sharp or flat, except E to F and B to C, which sit right next to each other. → **text only**
3. Press "Start calling notes". Find each called note on string 6 or 5 before the next bar, starting from the nearest landmark. → **card + metronome**
4. Say the note out loud as you play it. → **card + metronome**
5. Aim for {target_reps} clean passes in a row. → **card + metronome**

### The B-string rule (card: neck_map, map: unisons)

1. Play string 6 at fret 5, then string 5 open: the same note, A. Each string is tuned to fret 5 of the string below it. → **card**
2. Check each pair up the neck: fret 5 on string 5 matches open string 4, and fret 5 on string 4 matches open string 3. Then the odd one out: fret 4 on string 3 matches open string 2. → **card**
3. Why the odd one out? Strings are 5 frets apart (a 4th), except strings 3 to 2, which are 4 frets apart (a major 3rd); that keeps chord shapes small enough for one hand. Finish with fret 5 on string 2 against open string 1, saying "five, five, five, four, five". → **card**
4. Aim for {target_reps} clean passes in a row, hearing each pair ring as one note. → **text only**

### Octave shapes (card: neck_map, map: octaves)

1. An octave is the same note, 12 frets higher. The card shows every {degrees:1} on the neck, joined by octave shapes. → **card**
2. Skip one string and go up 2 frets: string 6 to 4, or string 5 to 3. Skip two strings and go back 3 frets: string 6 to 3. → **card**
3. When a shape crosses from string 3 to string 2, add one fret: string 5 to 2 is back 2 frets, string 4 to 2 is up 3. That is the B-string rule again. → **card**
4. Press "Start calling notes". Find the called note on string 6 or 5, then its octave with a shape, saying the note name at both spots. → **note caller + metronome**
5. Aim for {target_reps} clean passes in a row. → **note caller + metronome**

### Interval shapes (card: neck_map, map: intervals)

1. Find {degrees:1} on string 6: that is the root (R). Every other dot on the card is measured from it. → **card**
2. The 3rd (a major 3rd) is one string up and one fret back; the 5th is one string up and two frets up. Play R, 3, 5 and say "root, third, fifth". In a minor key, use the b3, one fret lower. → **card**
3. The b7 is two strings up at the same fret, and the octave (8) is two strings up, two frets up. Play R, 3, 5, b7, 8. → **card**
4. Now start from {degrees:1} on string 5: the shapes are identical, because strings 5, 4 and 3 are also 5 frets apart. → **card**
5. Aim for {target_reps} clean passes in a row, naming each note's number as you play it. → **text only**

2. A stable line reads like a finished sentence; an unstable line trails off, like a question. Mark each line you wrote S or U. → **text only**
